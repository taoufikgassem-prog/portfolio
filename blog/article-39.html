Script Includes : réutiliser la logique serveur dans ServiceNow

Par Taoufik GassemPublié le 1 octobre 2025Mis à jour le 1 octobre 20258 min de lecture

Sommaire

Les Script Includes permettent de structurer et de réutiliser la logique serveur dans ServiceNow, évitant ainsi de dupliquer du code entre plusieurs Business Rules, UI Actions ou autres scripts serveur.

Qu'est-ce qu'un Script Include

Un Script Include est une classe JavaScript côté serveur, définie une seule fois et réutilisable partout où une logique serveur est nécessaire. Il permet de centraliser des fonctions communes, comme des calculs métier récurrents ou des vérifications de cohérence de données.

Le chargement à la demande

ServiceNow charge les Script Includes à la demande (lazy loading), ce qui signifie qu'ils ne consomment des ressources que lorsqu'ils sont réellement appelés. Cette caractéristique encourage la création de Script Includes bien découpés, plutôt qu'un unique fichier monolithique regroupant toute la logique.

Usages typiques

Les Script Includes sont couramment utilisés pour centraliser des règles de calcul complexes, exposer des méthodes utilisables à la fois par des Business Rules et par des Client Scripts via GlideAjax, ou encapsuler des appels à des systèmes externes.

Le lien avec GlideAjax

Lorsqu'un Client Script a besoin d'informations provenant du serveur sans recharger la page, il peut appeler un Script Include spécifiquement conçu pour être utilisé via GlideAjax, à condition de le déclarer comme accessible côté client de façon contrôlée et sécurisée.

Bonnes pratiques de structuration

Un Script Include bien conçu regroupe des responsabilités cohérentes, documente clairement ses méthodes publiques, et évite de mélanger logique métier et logique d'interface. Cette discipline facilite les tests et la maintenance dans la durée.

Checklist Script Includes

  • La logique serveur réutilisée à plusieurs endroits est centralisée dans un Script Include dédié.
  • Chaque Script Include a une responsabilité cohérente et documentée.
  • L'exposition via GlideAjax est limitée aux méthodes réellement nécessaires côté client.
  • Le découpage en plusieurs Script Includes reste lisible plutôt que fragmenté à l'excès.
Un Script Include bien structuré transforme une logique dupliquée en une fonction centralisée, plus simple à maintenir et à faire évoluer.

Conclusion

Les Script Includes sont un outil clé pour structurer la logique serveur dans ServiceNow, en favorisant la réutilisation et en limitant la duplication de code. Une organisation soignée de ces composants facilite grandement l'évolution d'une configuration ServiceNow dans le temps.
