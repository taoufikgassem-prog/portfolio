Ce dossier est destiné à contenir :

- cv-taoufik-gassem.pdf
  Le CV public de Taoufik Gassem, à déposer ici avec exactement ce nom de fichier.
  Une fois le fichier ajouté, ouvrez js/main.js et passez la valeur
  CV_AVAILABLE à "true" dans l'objet SITE_CONFIG en haut du fichier.
  Le lien de téléchargement sur les pages Contact et À propos s'activera
  automatiquement, sans autre modification.

- certifications/servicenow-csa.pdf
  Le certificat "ServiceNow Certified System Administrator (CSA)", à déposer
  avec exactement ce nom de fichier dans le sous-dossier certifications/.
  Une fois le fichier ajouté, ouvrez js/main.js et passez la valeur
  CSA_CERTIFICATE_AVAILABLE à "true" dans l'objet SITE_CONFIG.
  Le bouton "Voir le certificat" sur la page Certifications s'activera
  automatiquement.

Important : ne jamais utiliser un chemin local de type
file:///C:/Users/... dans les fichiers publiés. Seuls des chemins relatifs
(comme ceux déjà utilisés dans ce projet) fonctionnent correctement une fois
le site publié ou ouvert localement après extraction du ZIP.

Voir le fichier README.md à la racine du projet pour plus de détails.
